## About Wave PC

Wave PC v3.2 is a Windows desktop utility for running Lua scripts inside Roblox. It is intended for users who prefer a direct scripting experience, pairing a clean desktop interface with injection tools that require minimal setup. From task automation and custom game-logic testing to browsing community scripts, the application provides a practical starting point without a cluttered workflow.

Its design centers on dependable operation and ease of use. One-click injection removes unnecessary setup steps, while the integrated Script Hub offers more than 500 scripts in a categorized collection. Because the application is built with a lightweight structure, it is designed to operate alongside Roblox while using limited CPU and memory resources.

## Frequently Asked Questions

**Is Wave PC safe to use?**  
Wave PC is supplied as-is, and each user is responsible for following Roblox's terms of service. The software does not contain malicious components, although detection cannot be ruled out.

**Does it support the newest Roblox release?**  
The built-in updater is intended to maintain compatibility with current Roblox versions. When a Roblox update causes a problem, a replacement release is generally available within 24-48 hours.

**What makes Wave PC different from other executors?**  
The project prioritizes a simple interface and low resource usage. While it does not provide every advanced capability offered by premium executors, it supplies a free option backed by a broad script library.

**Could using it result in a Roblox account ban?**  
All third-party script executors involve account risk. Wave PC makes no promise of being undetectable, so use it at your own discretion.

**Where does Wave PC keep scripts and preferences?**  
Execution queues and preferences remain on the local machine in the `Queues/` directory and are managed with SQLite. No information is sent externally.
